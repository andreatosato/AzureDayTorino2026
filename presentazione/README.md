# Presentazione

[Apri il PowerPoint](MCP-A2A-Skill-AzureDayTorino2026.pptx).

19 slide principali e un'appendice fonti, con testi, diagrammi e note del
relatore modificabili direttamente in PowerPoint. Nessun generatore o
dipendenza Node.

Il deck e' allineato alle due demo implementate:

- **BASIC**: MCP, A2A e Skill isolati, con richieste dalla UI web.
- **ADVANCE**: un caso Commerce integrato con Skill, delega A2A e tool MCP.

Un unico AppHost mostra tutte le app, da avviare manualmente nella dashboard.
BASIC mostra i progetti MCP, A2A,
Skill e Orchestrator con il solo meteo in memoria; ADVANCE ha host di
protocollo e dati Commerce propri. Le slide riportano i nuovi nomi dei progetti.

Le slide mostrano responsabilita', file effettivi da aprire e dati del mock.
Le note del relatore includono il percorso da seguire nelle due UI.
Per avviare le demo, seguire il [README delle demo](../README.md).

Le risposte con un modello reale richiedono la propria configurazione;
non sono stati aggiunti risultati o benchmark LLM alla presentazione.
